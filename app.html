    Good to know

      Security & connection

      • Codes expire after 10 minutes and allow one viewer at a time. Every viewer must be approved on the sharing device, after checking that the 2-digit number matches.
      • Video and audio are encrypted end-to-end (WebRTC DTLS-SRTP) and go straight between the devices. The pairing server only passes the connection setup.
      • Both screens show the same security code once connected. If they match, nobody is in the middle.
      • The viewer can only point and draw if the sharer allows it, and it can never click or type on the sharer's device.
      • Both devices need internet access to pair. Some strict networks (corporate, hotel, some mobile carriers) block direct connections. Those need a TURN relay, which the site owner can configure.
      • No internet at all, for example in a classroom? Use Classroom, no internet. The Windows app connects straight to the panel, without any network.

      You are offline. The interface still works, but pairing and casting need a connection between the devices and to the pairing server.
